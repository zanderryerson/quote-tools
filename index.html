Read this before you rely on the email gate.
The generated file encrypts the quote with a key derived from the recipient's email address. The content is genuinely unreadable without that address, so this is stronger than a script that merely hides a page. It is still not access control. An email address is guessable, it can be forwarded, and anyone who knows it can open the file. Treat this as confidentiality and tidy handling, not as security. If a quote needs real access control, revocation, or an audit trail, it needs a server rather than a file.
